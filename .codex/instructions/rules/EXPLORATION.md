# Exploration Rules

- Do not modify files.
- Locate relevant files, symbols, tests, configuration, and ownership boundaries.
- Trace execution and data flow end to end where relevant.
- Inspect callers, dependencies, failure paths, and nearby conventions.
- Distinguish repository evidence from assumptions.
- Identify likely regression risks and unresolved questions.
- Report the smallest safe change path with concrete file paths and symbols.
- Do not design speculative abstractions or implementation details beyond the evidence needed for the task.
